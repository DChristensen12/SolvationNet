How to read this table
  • Verified = Yes means I read the value in a source and it is for that exact composition. Values for the 21 run boxes come from your CSV, whose sources I re-checked where I could open them. For the 43 new systems I read the numbers from the Geysens 2018 PDF, the Kumar 2026 arXiv PDF and the Hofmann 2022 SI.
  • Verified = No rows are existing boxes. The link is where I think the value is, not a source of one. Data found (interpolated) means a neighbouring measurement exists and I interpolated; Probable means a paper covers that system but I could not see the number; Speculative means a topical match only.
  • ps ran is NPT time with Nitro. Converged uses drift under 1% between the last two windows; for 100 ps boxes the stricter ps 50 to 100 window is quoted where the full-run drift failed.
  • Units differ between sources. Check the note on a row before comparing it to a simulated density: molar means mol per litre of solution, molal means mol per kg of solvent.
  • Whether a system started from an NVT box is not shown, as you asked. The 36 lead rows are boxes in NVT_OrbMolV2.
